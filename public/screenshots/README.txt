Drop your real app screenshots in this folder. Use these exact file names:

  dashboard.png        (main chat window; also used in the hero section)
  signup.png           (sign up screen)
  otp.png              (OTP verification screen)
  login.png            (login screen)
  forgot-password.png  (forgot password screen)
  settings.png         (settings screen)

Until a file exists, the website automatically shows a styled mockup in its place,
so the site never looks broken. Recommended size: about 1280x800 px, PNG or JPG
(keep the .png extension, or change the file names in src/data/content.js).
